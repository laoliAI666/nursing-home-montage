# 养老院素材混剪

提供单家机构的实拍素材和事实文本，用自然语言指定数字人和数量，生成竖版混剪与完整社交媒体发布包。支持多人共享服务连接、批量排队和断点恢复。

例如：“用这个机构的素材，全部已配置数字人，每人做三条不同的视频。”

首次使用由智能体只收集缺项：人物原图、社媒署名、录音或已有音色，以及必要的服务连接。个人咨询钩子可输入、选择推荐或跳过；用户无须编辑 JSON。

实际制作默认启动内置本地工作台并打开页面，Codex / WorkBuddy 共用同一套入口和队列；用户明确不要页面时直接本地执行。发布包含 MP4、封面 PNG、发布标题／描述／五个话题 TXT，封面在工作台编辑并自动更新首帧。完成后待验收；点击验收直接后台清理，无需二次确认。删除任务会清理任务数据，成品独立保留在成品库。可在成品库单独永久删除某条视频及其全部版本。入口与验收见[工作台](references/workbench.md)。

工作台提供机构资料库、制作任务、成品库、数字人与配乐管理，支持批次和单条偏好、封面编辑及单条重做。同一队列严格按提交顺序逐项制作；多条视频先统一策划素材、口播和分镜，再分别执行，避免各条重复。用户可查看阶段进度和最近回传，验收及任务删除均在后台清理。

固定采用全屏橙色正文与青绿首帧封面，1080×1920/30fps，默认包内手写字体和BGM；字幕避让依据项目平台截图调整。需要 Python 3.11、uv、Node/npm、FFmpeg；使用锁定渲染依赖，付费前先验证浏览器与内容。用户提供自己的服务账号、音色与人物，也可明确覆盖字体／配乐。

入口：[SKILL.md](SKILL.md)。具体初始化、计划、制作、封面、钩子和批次说明均从入口按需读取。用户数据保存在项目 .montage、素材和作品目录，替换 skill 不重置配置，旧任务沿用绑定引擎。

需要新版时直接对智能体说“更新养老混剪到最新版”；只想查询时说“检查养老混剪更新”。按[版本更新](references/update.md)从[官方 GitHub 最新正式 Release](https://github.com/laoliAI666/nursing-home-montage/releases/latest)获取运行包并校验，保留项目资料和旧任务。首次使用该入口须先安装包含这条规则的版本。

此运行包不包含机构实拍素材、个人人物、账号、凭据、开发测试或发布工具。运行版本见 VERSION/release.json；第三方许可见 THIRD_PARTY_NOTICES.md 和 LICENSE。
