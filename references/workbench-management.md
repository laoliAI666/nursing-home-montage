# 工作台进度与管理

## 真实进度

详情显示整批阶段百分比、当前活动、运行标识、状态更新时间与网页连接状态。百分比由实际回传的阶段汇总，是阶段估算，不是已耗时间或剩余时长；长接口等待时保持不变。动画表示任务状态，不证明供应商持续推进。超过三分钟无回传时显示等待新阶段，不宣称失败或自动释放队首。

页面也读取当前执行条目的 state.json，补足 Agent 漏报阶段时的展示；只使用本次领取之后写入的已知检查点，并标记“本地工程检查点”。此读取不回写队列、不释放租约，不因本地 complete 就直接显示制作完成。

新子 Agent 在阶段切换、接口提交和结果检查点 report，长接口轮询至少每 60 秒回传同阶段的真实说明。主协调者不伪造进度。页面轮询串行执行，避免较早请求覆盖较新状态；旧页面需刷新一次载入升级后的前端。

多条新批次先显示独立的整批策划行；素材整理与批准计划完成后，前两阶段计入所有视频的阶段估算。视频完成条数仍只统计视频。接单连接变化也更新当前提示；“页面同步正常”不等于主 Agent 正在接单。断开时重试保留顺序并保存恢复请求，主 Agent 在线则从原序号重新派发；主对话已经关闭时，页面给出连接入口，不宣称会自动唤醒关闭的宿主对话。

## 删除任务与保留成品

不再提供回收站或恢复。任务、机构、素材、数字人及配乐支持单项和同列表多选删除，删除前展示对象、阻止原因及保留范围，确认后执行。验收按钮独立采用直接异步清理，不弹窗。

删除任务先把所有已完成版本的 MP4、PNG、发布文案和三文件 ZIP 按哈希核验后独立保存在 `.montage/workbench/products/ID/`，再后台清理本任务工程、临时网页、日志、配音、数字人、固定输入与配乐副本、编辑缓存、子 Agent 及连续执行记录，最后移除任务和队列记录。只留成品索引，不把历史任务伪装为未清理的回收站。成品库与机构成品页独立读取该索引，可预览、切换版本和下载。成品卡片上的「删除成品」需确认，随后永久清理所选视频的全部版本、封面、发布文案及发布包。任务删除后编辑上下文已清理；要重新制作，从机构资料新建任务。删除不等于认可内容，不自动记录用户验收。

草稿或已取消且没有成品的任务同样可清理。清理请求持久化、逐项后台执行，失败保留成品与待处理记录，可重试；重启恢复未完成请求。先检查全部批量选择，运行、未确认退出、正在验收清理或被其他工程引用时不受理。删除接口不停止 Agent、不越过制作队列。共享资产仅解除本任务引用；原始机构资料、人物和外部文件不随任务删除。

删除机构、素材、非默认人物及非默认配乐会移除目录中的记录和自有副本，保留外部原文件、已完成成品以及其他资源的引用保护。仍在使用或用于任务恢复的资源先处理关联任务。成品本身和认可样片不提供删除按钮。旧版回收站清单不再隐藏现有内容，也不自动代用户清理历史文件。

新布局的批次删除后，交付文件留在该批次各视频的「交付产物」，成品库保留索引。旧任务仍用原归档目录。原视频、封面、文案的校验通过后才清理工程；网页按需生成下载 ZIP。

## 统一展示与诊断

制作任务页的「项目总览」按批次统计总任务、制作中、排队中、需处理与待验收。点击数字查看明细，排队批次按提交顺序排列，批次内待执行的视频与封面操作可一并查看。需处理的情况优先显示在数字下方，随后展示当前制作、下一批、待验收或最近完成的成品。

任务详情只保留一个“本批制作”区域，集中展示阶段估算、当前活动、流程与逐条视频。制作动态保留单独的历史记录。

“刷新状态”和“查看状态诊断”只发读取请求，立即展示 Agent 最近回传、本地产物更新时间、进度依据与执行锁情况。旧“正在检查当前制作状态”是控制请求的占位说明，不能覆盖真实进度；待主对话领取、已交给 Agent 和已收到结果分开显示。核查尚未领取不代表制作暂停。用户只有在异常处理里明确请求才向协调者发核查；正常刷新不操作执行锁，也不宣称宿主已断连或已恢复。

## 已保存凭据的显示

设置页默认只取凭据是否已配置。用户点击小眼睛时，通过同一已认证本地会话按需读取该项值，响应不缓存；普通状态接口不返回凭据。临时只读显示不带表单字段名，保存其他设置不会把查看值重新写入配置。再次点击、离开设置、页面隐藏或 30 秒后清空显示。新填写的值仍按正常表单保存。

## 成品修改队列

任务详情的“本批制作”同时显示视频列表与本批“成品修改”。首帧更新从同一 FIFO 读取状态及当前位置，提供编辑入口和取消操作，不计入视频完成条数。仅封面状态变化也刷新该区域；编辑页提交后提供返回本批进度的入口。全局队列仍展示所有批次及首帧任务。

## 取消与退出确认

运行中显示“请求停止”。停止已提交但执行者未回收时显示“取消中”，当前视频队首提供“请求确认结束”；该按钮沿用原生执行者核查协议，待领取时禁用重复请求，不直接释放执行锁。制作完成而未回收的执行者也可请求确认结束，成品保留。执行者回收后，取消项显示已取消及执行者已结束，不沿用旧的等待说明。

## 一键验收与后台清理

验收按钮直接提交，不弹窗。验收结果与清理结果分别保存：已验收的任务可以处于清理排队、清理中、已清理或清理失败。列表和详情展示状态，失败可重试；无需再次验收。清理期间可以查看、下载成品，修改封面和重做待清理结束后进行。

新工程共享只读源字体与固定依赖，各条独立保存计划、时间线、审核及输出。抠像完成后删除可从已核验原片重建的中间片；发布包直接从成品生成，不重复建立交付视频目录。渲染输出与正式成品可共享同一数据，重渲染前分离，避免改变已发布结果。清理一个任务只解除本任务的引用；其他任务与原始资料保留。
