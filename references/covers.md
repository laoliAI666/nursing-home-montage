# 风格库与自适应封面

新任务默认采用 01 号基线（`teal-adaptive` C 款青绿拼贴），同时内置 30 套涵盖横版 1/2/3/4 图构图、大主角人物呈现与静态装饰贴图的封面样式（`assets/styles/catalog.json`），并支持在项目 `.montage/styles/covers/` 放入 JSON 扩展更多样式（非基线图片槽位强制宽高比 `>= 0.90` 防竖裁切）。所有封面均仅用本地 HTML/Canvas 代码渲染，制作过程中不调用生图 API，不重生成人脸。开关与字段见 [计划格式](plan-schema.md)；运行与发布包见 [运行](runtime.md)。

## 内容和身份

01 是项目确认的固定头标（settings.cover.header_text），不随每条视频改写。02/03 合为一份 main_title，分两行展示，可明确 lines 或自动断行，保留原词高亮。04/05/06 是三枚可选不同文本的标签，必须共用同一字号；卡片分别伸缩。每张图优先对应标签，同机构内不完全对应可继续并记录来源。

07 署名直接读所选人物绑定的社媒名，缺失请用户指定，只要名字；固定人物和署名一起换。08/09 合为一个完整院名字段，只读核验后的 institution.name，不用 displayName，不省略地区、括号或机构类型。机构全称是本条输入，不与人物长期绑定。

照片来自本条同机构素材，可以从实际混剪视频提帧或取真实照片；素材有限允许复用同机构图，不借其他机构画面。计划逐槽保存 source、可选 time/crop/focus 和匹配说明。

## 封面和发布标题怎么写

- 封面主标题先写一句完整的大白话，再按语义换成两行。可以在完整主语或时间短语之后换行，下行接着把这句话说完。合起来朗读一遍，确认像平时说话。遇到两句各说各的、连问两个问题，或为了凑字数把词组拆开，先把整句重写顺，再调整断行。
- 封面和发布标题都用中老年人一遍能听懂的词。优先用“怎么住”“平时谁照顾”这样的日常说法。缩短时先取舍要讲的信息，保留理解所需的主语、动作和对象。用[自然表达润色](narration-polish.md)检查生硬省略、堆词和硬转折。
- 综合稿的标题要给观众正确的预期。可以从房间、院子或某项照护切入，并用整句让人知道还会看到院里的生活或照顾安排。散步、下棋、夜间照料这类细节可在正文带到，有对应实拍也可做图片标签。整条正文主要围绕这件事讲时，才用单个细节作为整条标题。
- 发布标题跟本条封面的切入点和正文范围一致，可以换一种说法。发布描述保留本条讲到的核心特点及已确认的咨询动作。同一家机构批量改写时，共同核心可以重复，描述可换顺序和说法。

以下示例里，斜杠只表示封面上的换行。

| 封面标题 | 发布标题 | 可以对应的综合稿 |
|---|---|---|
| 咱们来看看 / 这家养老院 | 跟着镜头看看这家养老院 | 从院区、居室和活动空间带看，交代日常照料 |
| 来看看长辈 / 在院里怎么生活 | 看看长辈在养老院平时怎么过 | 从居住、活动讲到平时有人照顾 |
| 这家养老院 / 也照顾失智老人 | 看看这家有失智照护的养老院 | 讲全院的分区、生活与服务，重点带到失智照护 |

## 发布标题的字数

先确认本次发布的平台和实际填写的字段。平台有“短标题”时核对该字段，发布描述另外按对应字段处理。优先查当前发布入口和平台说明，确认上限、计数方式和可用符号。

多平台共用一条发布标题时，取目标平台中已确认的最小上限，同时满足各平台的最低字数和字符要求。写完逐条计数。封面上的两行字按本模板实际测量。有平台上限暂时查不到时，说明哪个字段尚未核验，并说明本稿采用的暂定字数。

## 排版与渲染

assets/covers/teal-adaptive/layout.mjs 是唯一字号／间距／边界来源（BOUNDS），交互 HTML 和离线生产共用，不在文档复制数值表。按真实字形边界测量，标题两行同字号、三标签同字号，院名最多两行；调整宽高、居中及字号，不拉伸字形或截断。达到下限仍溢出时改文案或明确调整布局。参考标题每行约 4–7 个汉字，实际以测量为准。

通用字体为包内黑体，项目 settings.cover.font 可显式覆盖；封面字体与正文手写字幕字体独立。已有 cover_portrait 优先复用；否则 HyperFrames 本地 remove-background 处理头像，缓存到人物私有目录，轮廓描边由 Canvas 生成。私有图像和绑定不进入公共模板。

cover.py 选图／提帧、准备输入和编辑器，cover_renderer.mjs 复用锁定 HyperFrames 浏览器运行时导出 PNG。运行 `montage.py cover <job>` 会生成 cover.png、cover.json、cover-editor.html 并重新 compose。PNG 和 HTML 必须与输入指纹一致，布局通过后才能渲染。

## 视频首帧和覆盖

封面层只覆盖 [0,1/fps)，次帧回到正文原时间点；不插入片头秒数、不偏移音频和字幕。静态封面不改变正文首镜头运动视频要求，也不改变正文模板和字幕字号。

本次 settings.cover.enabled=false 可关闭；提供 settings.cover.image 时使用该 1080×1920 原图，否则自动生成。原图先显示在编辑 HTML，改动后按 C 款重排。封面／文字与原图需语义对应，由智能体核对。新封面导出后，需通过制作流程更新视频首帧；浏览器不会自动改包内 MP4。

默认发布包只含最终 MP4、独立封面 PNG 与发布 TXT，封面编辑 HTML 在工程内部供工作台使用。明确要求离线编辑器时才额外交付 HTML。内部 cover.json 合并输入、素材来源、布局诊断与哈希，不拆成多份清单。
